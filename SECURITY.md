# Security and Data Handling

Do not commit employee records, personally identifiable information, credentials, access tokens, or private model artifacts to this repository. The raw-data and generated-artifact paths are ignored by default, but verify `git status` before every push.

This project is for decision support and demonstration. Do not use predictions as the sole basis for employment decisions. Validate privacy, fairness, access controls, and applicable employment regulations before using real HR data.

To report a security issue, use GitHub's private security advisory workflow for this repository rather than posting sensitive details in a public issue.
